Logical Flow Reading Guide

A compact way to read the Southbound logical flows generated by ovn-northd.

Command

ovn-sbctl lflow-list sw0
ovn-sbctl lflow-list lr0
ovn-sbctl lflow-list sw1

Each logical switch or logical router is a logical datapath. lflow-list shows the flows for that datapath.

Flow Shape

table=0 (ls_in_port_sec_l2), priority=50, match=(...), action=(next;)

Table

The stage in the logical pipeline. Lower table numbers run before later tables.

Priority

When several flows in the same table match, the numerically highest priority wins.

Match

The packet condition, such as inport, eth.src, ip4.dst, or outport.

Action

What OVN does: next;, drop;, header rewrite, or output;.

Mental Algorithm

  1. Start at table 0 in the selected pipeline.
  2. Find flows whose match is true for the packet.
  3. Choose the highest priority among matching flows.
  4. Execute the action.
  5. If the action is next;, continue to another table. If it is output;, move toward delivery.
